# ReviewPilot — Prompt Engineering Guide

> This document describes the prompt strategy used by the AI Review Response
> Generation Engine. The actual code lives in `lib/prompts.js`.

---

## Architecture: Two-Layer Prompt System

Every review response is generated from two prompt layers:

```
┌────────────────────────────────────────────────┐
│  SYSTEM PROMPT (set once per business)          │
│  • Role definition                              │
│  • Business context (name, type, voice)         │
│  • Core rules (be specific, authentic, concise) │
│  • Tone guidelines per rating tier              │
└────────────────────────────────────────────────┘
                        ↓
┌────────────────────────────────────────────────┐
│  USER PROMPT (per review)                       │
│  • Review text, rating, reviewer name           │
│  • Sentiment-specific extension (if needed)     │
└────────────────────────────────────────────────┘
```

---

## System Prompt Template (Business Context)

```
You are ReviewPilot, an AI assistant that helps local service businesses
craft authentic, personalized responses to customer reviews. You write in
the business owner's voice.

BUSINESS CONTEXT:
- Business Name: {businessName}
- Business Type: {businessType}
- Brand Voice: {brandVoice}
- Signature Style: Sign with "{signWith}"

CORE RULES:
1. Be specific — reference details the reviewer mentioned
2. Be authentic — never sound like a template or form letter
3. Be concise — maximum 180 words
4. Use natural language — no markdown, no emoji, no hashtags
5. Never mention: "ReviewPilot", "AI", "automated response", "generated by"

TONE GUIDELINES BY RATING:
- 4-5 stars: Warm, grateful, affirming. Match the reviewer's enthusiasm.
- 3 stars: Appreciative, receptive, open. Thank them for balanced feedback.
- 1-2 stars: Empathetic, accountable, solution-oriented. Apologize sincerely.
  Offer to make it right. NEVER be defensive or dismissive.
```

### Brand Voice Options

| Voice | Description | Best For |
|-------|-------------|----------|
| `professional` | Polished, courteous, slightly formal | Law firms, financial advisors |
| `warm` | Friendly, personal, approachable | Dental clinics, therapists |
| `casual` | Relaxed, conversational, natural | Auto repair, plumbers, HVAC |
| `family-oriented` | Caring, inclusive, community-focused | Pediatricians, family restaurants |
| `formal` | Very proper, traditional | High-end services, luxury |

### Signature Style Options

| Style | Example Closing |
|-------|-----------------|
| `we` (default) | "Thanks again, — The Downtown Dental Team" |
| `first-person` | "Thanks again, — Dr. Smith" |
| `business-name` | "Thanks again, — Downtown Dental" |

## User Prompt (Per Review)

### Base Template
```
Please write a response to this review:

Rating: {rating}/5
Reviewer: {reviewerName}
Review: "{comment}"

Write the response now. Return ONLY the response text — nothing else.
```

### Negative Review Extension (appended for 1-2 star reviews)

```
IMPORTANT — This is a negative review. Follow these guidelines:
1. Acknowledge the customer's specific complaint
2. Apologize sincerely and take ownership
3. Briefly explain any corrective action (if appropriate)
4. Offer to connect offline to resolve personally
5. Thank them for the feedback
DO NOT: make excuses, blame the customer, be defensive, or use legal language.
```

### Positive Review Extension (appended for 4-5 star reviews)

```
IMPORTANT — This is a positive review. Write a short, warm response:
1. Thank the reviewer by name
2. Reference something specific they complimented
3. Express appreciation and invite them back
Keep it to 2-3 sentences, under 80 words.
```

## Advanced: Structured Output Prompt (Single Call)

For cases where we want sentiment analysis + response in one API call,
use this JSON-format prompt instead:

```
Analyze this review and generate a response.

REVIEW:
Business: {businessName} ({businessType})
Rating: {rating}/5
Reviewer: {reviewerName}
Review: "{comment}"

Respond in this exact JSON format (no other text):
{
  "sentiment": "positive|neutral|negative",
  "urgency": "low|medium|high",
  "key_themes": ["theme1", "theme2"],
  "draft_response": "Your generated response here"
}

Guidelines:
- "sentiment": positive (4-5★), neutral (3★), negative (1-2★)
- "urgency": high if business reputation at risk; medium for notable complaint; low for positive
- "key_themes": extract 1-3 main topics from the review
- "draft_response": the full response following the brand voice rules
```

**Why use this?** Avoids needing two separate API calls (one for analysis,
one for draft). Cost savings: ~50% fewer tokens.

## Example Responses by Rating Tier

### 5-Star (Positive) — Short & Warm
> **Review:** "Dr. Lee is amazing! She made my root canal painless. The staff is so friendly."
>
> **AI Draft:** "Thank you so much, Sarah! We're thrilled you had a great experience with Dr. Lee. She truly cares about making every visit as comfortable as possible. Looking forward to seeing you again! — The Downtown Dental Team"

### 3-Star (Neutral) — Appreciative & Open
> **Review:** "The food was good but the wait was longer than expected."
>
> **AI Draft:** "Thanks for your honest feedback, Mike. We're glad you enjoyed the food, and we hear you on the wait time — we've been working on streamlining our dinner service, and your input helps us improve. Hope to serve you again soon! — The Bistro Team"

### 1-Star (Negative) — Empathetic & Solution-Oriented
> **Review:** "Terrible experience. They overcharged me and refused to fix it."
>
> **AI Draft:** "Hi James, I'm very sorry to hear about your experience. This isn't the standard we aim for, and I'd like to personally look into the billing issue you mentioned. Please email us at support@example.com so we can make this right. Your feedback helps us do better, and we appreciate you bringing this to our attention."

## Provider Selection Strategy

| Sentiment | Primary Provider | Fallback | Rationale |
|-----------|-----------------|----------|-----------|
| Positive (4-5★) | OpenAI GPT-4o-mini | — | Fast, cheap, good enough for simple thanks |
| Neutral (3★) | OpenAI GPT-4o-mini | — | Balanced — doesn't need extra nuance |
| Negative (1-2★) | OpenAI GPT-4o-mini | → Claude 3.5 Haiku | Start cheap, escalate to Claude if more empathy needed |

The code automatically routes negative reviews to Claude if `ANTHROPIC_API_KEY` is
available and no provider override was specified. This gives us the best of both
worlds: cost efficiency at volume, and higher-quality handling of the most
sensitive reviews.

## Token & Cost Budgeting

**At scale (200 reviews/month per business, 50 businesses = 10k reviews):**

| Tier | Reviews/mo | AI Cost (OpenAI primary) | AI Cost (w/ Claude for ~10% negatives) |
|------|-----------|--------------------------|----------------------------------------|
| Starter | 50 | ~$0.005 | ~$0.009 |
| Growth | 200 | ~$0.02 | ~$0.036 |
| Pro (10 locations) | 2,000 | ~$0.20 | ~$0.36 |

AI costs are negligible compared to our subscription fees ($29-$99/mo).
Revenue per business is 100-500x the AI cost.

**Tight Budget Optimization:**
- Use `gpt-4o-mini` for ALL reviews (skip Claude fallback)
- (~$0.00002/review — even cheaper)
- Lower `max_tokens` to 200 for positive reviews
